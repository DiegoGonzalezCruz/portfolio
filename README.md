## Getting Started

This is my portfolio, built with [Next.js](https://nextjs.org) (App Router), React, TypeScript and Tailwind CSS. The contact form sends email through AWS SES.

If you want to check my code, install the dependencies and run the development server:

```bash
pnpm install
pnpm dev
```

The contact form needs `SYSTEM_AWS_ACCESS_KEY_ID` and `SYSTEM_AWS_SECRET_ACCESS_KEY` in `.env`.
